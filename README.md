## Pomodoro para devs

Gosto de usar o pomodoro para manter o foco, porém num contexto de desenvolvimento de software ele acaba interrompendo o estado de foco que entramos (onde somos mais produtivos).

O pomodoro reverso funciona da seguinte maneira, ao invés de ter um timer, você tem um cronômetro que mede quanto tempo você ficou focado na atividade, quando você mesmo sentir que precisa dar uma pausa, você para o cronômetro e o sistema calcula a sua pausa. (tempo de trabalho / 5 = tempo de descanso)
